# Sistema de Gestão - Protocolo Sepse 🏥⏱️

Este projeto foi desenvolvido para a disciplina de **Programação Avançada** e consiste em uma ferramenta de suporte à decisão clínica, focada no controle de tempo crítico para o tratamento da Sepse em ambientes hospitalares.

## 📝 Contexto e Problema
A Sepse é uma das maiores causas de morte em hospitais, muitas vezes devido a sinais que passam despercebidos ou falhas no controle do tempo. Este sistema digitaliza esse controle, cronometrando prazos e criando checklists obrigatórios para garantir a administração de antibióticos e exames no prazo crítico.
